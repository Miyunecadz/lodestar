---
id: protect-laravel-generated
title: Protect Laravel generated and cached artifacts
category: generated
severity: block
recommended: true
stacks: [laravel]
event: file
pattern: '(^|/)(bootstrap/cache/|storage/framework/|public/(build|hot|storage)/|public/mix-manifest\.json$)'
surface: agent
emits: rule
---

These are generated by the framework or the asset pipeline, not written by hand:

- `bootstrap/cache/` — compiled config/route/service caches. Regenerate with `php artisan optimize:clear` (or the specific `config:clear` / `route:clear`).
- `storage/framework/` — compiled Blade views, sessions, cache. Regenerate by clearing (`php artisan view:clear`).
- `public/build/`, `public/hot` — Vite output. Regenerate with `npm run build` / `npm run dev`.
- `public/storage` — the symlink from `php artisan storage:link`.
- `public/mix-manifest.json` — Laravel Mix output.

Editing them is overwritten on the next build or cache warm. Change the **source** — the config file, the route file, the Blade template, the asset entry point — and regenerate.

---

**Surface: `agent`.** These paths are usually gitignored, so there is normally nothing staged for a commit-time check to see; where a repo *does* commit built assets, blocking the commit would stop a legitimate build artifact from landing. Sibling of the universal [[protect-generated-files]].
