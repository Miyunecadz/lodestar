---
id: protect-dbmate-schema
title: Protect the dbmate-generated schema
category: database
severity: block
recommended: true
stacks: [node-dbmate]
event: file
pattern: 'db/schema\.sql$'
surface: agent
emits: rule
---

`db/schema.sql` is generated by dbmate; hand-edits are overwritten on the next migrate and cause drift between the file and the real database. Change the schema by writing a new migration instead — `schema.sql` updates itself when the migration runs.

---

**Surface: `agent` only.** `db/schema.sql` is *meant* to be committed — dbmate regenerates it on every migration. A commit-time check cannot tell a legitimate regenerated schema from a hand-edit, so enforcing there would block normal migration work.
